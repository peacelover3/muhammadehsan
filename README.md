# Muhammad Ehsan — portfolio

Responsive React portfolio for Muhammad Ehsan, built with Vite and Framer Motion.

## Run locally

```sh
npm install
npm run dev
```

Create a static production build with `npm run build`; Vite writes it to `dist/`. The résumé is served from `public/Muhammad_Ehsan.pdf`.

## Content and design

Portfolio content is based on `Muhammad_Ehsan.pdf`. The six project descriptions distinguish the product from Ehsan's contribution. The interface panels are illustrative CSS artwork, not screenshots of the products. No project outcomes, public demos, client names beyond the résumé, testimonials or certifications have been invented.

The page uses a dark green and teal palette, editorial typography and low-key motion. It respects reduced-motion preferences, uses responsive layouts and includes keyboard focus states.
